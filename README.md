# Portal Kombat

Мобильный файтинг с порталами. Играть: **https://kur0sava.github.io/portal-kombat/**

Это **грей-бокс**: бойцы — палки на шарнирах, арены — коробки, звука нет.
Смотреть надо не на картинку, а на то, читается ли бой.

## Управление

Движение: `A` / `D` — шаг, `S` — присед, `W` — сайдстеп, двойное `D` — рывок, `L` (держать) — блок.

Удары — две кнопки, направление выбирает приём:

| Ввод | Рука `J` | Нога `K` |
|---|---|---|
| без направления | лёгкая | прямой ногой |
| `S` + | лоу | подсечка |
| `W` + | оверхед | хай-кик |
| `D` + | лончер (подброс) | толчок |
| `A` + | тяжёлая (ломает блок) | вертушка |
| `+ L` | бросок (игнорирует блок) | бросок |

Порталы — кнопка `I`: сам по себе — Rift Step, `W`+`I` — Anchor, `D`+`I` — Mirror.

`F1` — хитбоксы и кадры, `F6` — замедление до 1/8, `F7` — старые капсулы вместо скелета.

## Главное правило

**У портала нет владельца.** Открыл проход, чтобы сбежать, — противник заходит следом.
Выход Step ложится в случайную точку арены: игрок решает открыть проход, но не решает,
куда он выведет.

## Что тут есть

Три бойца (труба, нунчаки, двуручная палица), восемь арен со своими правилами, граф мира
с переходами по исходу боя, разломы — цепочки боёв без восстановления здоровья, боссы,
которые ломают по одному правилу боя, двенадцать перков, снаряжение и прокачка приёмов.

Чего нет: моделей, анимаций, звука и онлайна. Это следующий этап.
